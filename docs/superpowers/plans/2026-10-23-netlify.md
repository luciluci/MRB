# MRB Netlify Deployment Implementation Plan

**Goal:** Deploy the working MRB demo on Netlify and embed it in Alpacas page 10693.
**Architecture:** Retain Next.js routes; add conditional snapshot storage using Netlify Blobs. Keep file storage locally.
**Tech Stack:** Next.js 16, TypeScript, Netlify Blobs and Netlify Next.js adapter.
**Spec:** ../specs/2026-10-23-netlify-design.md

## Constraints and review focus
- Never upload local data/state.json, environment secrets, dependencies, or build output to GitHub.
- Concurrent mutations must not silently overwrite one another; stale store revisions still reject.
- Missing storage seeds the demo; storage failures must not look like missing data or successful writes.
- Production and preview state are separate. Local tests keep file storage.
- Retain demo labeling and omit the WordPress Search widget.
